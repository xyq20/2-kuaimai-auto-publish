# 模型学习规则边界

版本：human-grounded-rules-v1。

## 执行顺序

沿用 Excel 明确匹配、人工确认、既有审核学习在先的流程；仅进入语义判断阶段后检索模型归纳规则。规则不能改变执行顺序、权限、保存校验或发布行为。

## 模型职责

模型随字段判断归纳规则建议；规则按平台、类目叶子、字段名称、控件类型、Excel 完整原文限定范围，不生成可执行代码。模型输出不可信，程序校验后才储存或复用。未配置模型时不会新增提议。

## 自动规则

首批仅开放风格、细分风格、基础风格、版型、版型分类、服装版型的等价映射。至少三个不同款号的人工记录、对应意图完全一致、相关记录全部同意、无不填写或其他选择冲突。重复运行同款不增加样本数。保存回读和模型自己的输出不计人工票。

数字、事实推断、类目、年龄、材质、品牌、价格库存等不自动固化。历史截断、候选缺失/重名/集合变化、单多选不符、操作失败待审核均阻止自动复用。当前回测是对相关人工记录的一致性验证，不代表独立留出集准确率。

## 复杂规则审核

工作台“学习规则审核”展示模型提议、精确范围、人工证据和验证结果。人工同意后状态为 approved_guidance，仅作为下一次模型判断的参考；仍须检查商品事实、Excel 原文、候选、语义置信门槛及回读，不能直接运行复杂操作或改变硬约束。未批准的提议不进入模型上下文。

## 版本、纠正和停用

规则按策略版本、范围、证据与提议生成唯一版本。每次复用重新校验；冲突、候选变化会暂停自动规则，人工证据或候选变化会暂停已批准参考规则。审核和停用操作有独立记录。停用不修改历史商品或历史审核。新提议不会直接覆盖被停用的相同版本。

每次字段调用顺便梳理，不另起周期后台训练；尚未提供批量全库归纳、自由文本修改规则或通用可执行复杂规则。日志与判断看板记录规则 ID、验证结果和独立样本数。
