# 后台经验整理与复用

模型随字段判断整理学习库，不设独立规则审核流程。不确定的商品字段统一进入原有商品属性审核。

## 优先级与边界

保留 Excel 明确匹配、人工确认、既有审核学习在先的流程。模型不能改变执行顺序、权限、保存校验或发布行为，也不能生成可执行程序。整理出的经验按平台、类目叶子、字段、控件类型、Excel 完整原文限定范围。

首批自动映射仅开放风格、细分风格、基础风格、版型、版型分类、服装版型的等价映射。至少三个不同款号的人工记录，相关意图完全一致、无不填写或其他选择冲突。重复运行同款不增加样本数。保存回读与模型摘要不计人工票。

复杂经验在后台保存为 advisory，仅供模型参考，明确标注 model_summary、human_confirmed=false。事实推断、类目、年龄、材质、尺寸、品牌、价格库存等不能由摘要直接自动填写。摘要不是训练后的模型参数，也不代表已获人工确认。

## 持续更新

每次命中重新验证；人工证据或候选变化会暂停过期摘要。新判断可以产生新版本。历史截断、候选缺失/重名/集合变化、单多选不符、页面操作失败均阻止直接复用。暂停、停用版本及历史审核记录保留。

摘要只取当前范围最新有效的一条，避免反复堆叠；通过验证的简单规则省去模型调用。原始人工记录仍用于事实核对和冲突检测。日志与判断看板记录规则 ID、验证结果和独立样本数。

模型在需要判断字段时同步整理，无额外周期训练任务。历史记录一致性校验不等同于独立留出集准确率。
